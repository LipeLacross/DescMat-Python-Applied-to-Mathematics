# DescMat - Python Applied to Mathematics

This repository contains the material and code developed during the *DescMat - Python Applied to Mathematics* course. The course covers a wide range of topics in programming and computational mathematics, with a focus on tools such as Python, mathematical libraries, and data visualization techniques.

## 🔨 Project Features

The project is structured into lessons that cover the following topics:

- **Lesson 1**: Fundamentals of programming
- **Lesson 2**: Functions and conditional structures
- **Lesson 3**: Exercise resolution
- **Lesson 4**: Array structures and loops
- **Lesson 5**: Advanced problem-solving exercises
- **Lesson 6**: Object-Oriented Programming (OOP)
- **Lesson 7**: OOP review and problem-solving
- **Lesson 8**: Data persistence and version control
- **Lesson 9**: Using Numpy and Matplotlib
- **Lesson 10**: Introduction to Pandas
- **Lesson 11**: Applications with SymPy
- **Lesson 12**: Introduction to machine learning (ML)
- **Lesson 13**: Mathematical visualization with Manim

## ✔️ Techniques and Technologies Used

- **Python**: Main language for coding exercises.
- **Jupyter Notebooks**: Interactive environment for running notebooks.
- **Numpy, Pandas, SymPy, Matplotlib**: Mathematical and visualization libraries used in the practical activities.
- **OOP (Object-Oriented Programming)**: Implementation of OOP concepts in various activities.
- **Manim**: Visualization tool for mathematical animations.
- **Machine Learning (ML)**: Introduction to machine learning and its use in mathematical problems.

## 🛠️ Running the Project

To run the project locally, follow the steps below:

1. **Make sure Python is installed**:
    - [Python](https://www.python.org/) is required to run the notebooks. Check if Python is installed with:
      ```bash
      python --version
      ```
    - If it's not installed, download and install the recommended version.

2. **Clone the Repository**:
    - Copy the repository URL and run the following command in the terminal:
      ```bash
      git clone <REPOSITORY_URL>
      ```

3. **Install the Dependencies**:
    - Navigate to the project directory and install the necessary dependencies with:
      ```bash
      pip install -r requirements.txt
      ```

4. **Open the Notebooks**:
    - Use Jupyter Notebook to open and run the `.ipynb` files:
      ```bash
      jupyter notebook
      ```

## 🌐 Deploy

This project does not have a specific deployment phase, as it is intended for local learning and practice. Follow the steps above to set up and run the project in your local environment.
